Vague link on its own Fails

The University's main website has campus news, upcoming events, and links to every college and department.

Click here.

In a list of links, a screen reader user just hears "Click here." The description is in a different paragraph, so it doesn't count as the link's context.

The same vague link on every card Fails

Study rooms

Reserve a quiet room at the Marriott Library for up to four hours.

View details

Campus map

Find buildings, parking, and accessible entrances across campus.

View details

IT help desk

Get help with passwords, Wi-Fi, and campus software.

View details

Three links with the same text going to three different places. Out of context, there's no way to tell them apart.

Label field that leaves out the visible words Fails

Campus shuttle

Free shuttles connect the Union, the hospital, and Research Park.

Learn more

Parking permits

Buy or renew a permit for the semester or the full year.

Learn more

Biking and rolling

Bike racks, repair stations, and routes across campus.

Learn more

The CMS "screen reader label" field replaces the visible "Learn more" instead of adding to it.

Screen reader users: fine. They hear "Campus shuttle," which is clear.

Voice control users (people who operate the computer by speaking): they say the words they see, "click Learn more," but no link is named "Learn more," so the command doesn't find it.
