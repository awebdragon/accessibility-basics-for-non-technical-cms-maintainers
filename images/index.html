Who is most affected
  • People who are blind or have low vision
  • People with cognitive, learning, or language disabilities

Informative images

Images that carry information. The alt text should give the same information.

Missing alt text Fails

Welcome back! Fall semester is here, and campus is looking its best.

The image has no alt text at all, so a screen reader may read out the file name instead.

File name used as alt text Fails

Meet Pepper, the newest therapy dog visiting the library during finals week.

Some CMSs fill in the file name automatically. A tool can see the alt text is there, but only a person can tell it's meaningless.

Informative image marked as decorative Fails

Lost dog! Have you seen this dog? Last seen near the Union building on Tuesday afternoon. Please call the front desk if you spot him.

The photo is the most important part of this notice, but empty alt text (or a "decorative" checkbox) hides it from screen readers completely.

Decorative images

Images that add no information, often because the text next to them already says it. They should be skipped.

Decorative icon with alt text Fails

Location: Marriott Library, Level 1

The label already says "Location," so a screen reader hears "red location pin icon, Location: …" before getting to the point.

Functional images

Images that do something, such as a linked logo or an icon button. The alt text should say what happens, not what it looks like.

Linked logo with empty alt text Fails

The image is the only thing inside the link, so with empty alt text the link has no name. A screen reader just says "link."

Images of text

Images with words in them. The words need to be available as real text: in the alt text, or better, on the page itself.

Image of text with vague alt text Fails

New resource available for anyone filing a flood insurance claim:

The resource's title only exists inside the picture. Screen reader users hear "fact sheet graphic," and people who zoom in see blurry text.
