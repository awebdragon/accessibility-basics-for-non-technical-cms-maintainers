Who is most affected
  • People who are blind or have low vision

Informative images

Images that carry information. The alt text should give the same information.

Alt text that describes the photo Passes

Welcome back! Fall semester is here, and campus is looking its best.

The alt text describes what the photo shows, at the level of detail this short welcome message needs.

Description instead of a file name Passes

Meet Pepper, the newest therapy dog visiting the library during finals week.

The file name is replaced with a description of what the photo shows.

Informative image with alt text Passes

Lost dog! Have you seen this dog? Last seen near the Union building on Tuesday afternoon. Please call the front desk if you spot him.

The alt text gives screen reader users the same thing the photo gives everyone else: what the dog looks like.

Decorative images

Images that add no information, often because the text next to them already says it. They should be skipped.

Decorative icon with empty alt text Passes

Location: Marriott Library, Level 1

Empty alt text (alt="", or the CMS's "decorative" option) tells screen readers to skip the icon. The text label does the work.

Functional images

Images that do something, such as a linked logo or an icon button. The alt text should say what happens, not what it looks like.

Linked logo with alt text naming the destination Passes

The alt text names where the link goes, so the link now has a name.

Images of text

Images with words in them. The words need to be available as real text: in the alt text, or better, on the page itself.

Words moved onto the page, image made decorative Passes

New resource available for anyone filing a flood insurance claim:

Read the Flood Insurance Claims Checklist fact sheet on FloodSmart

The title is now real text on the page, so the image no longer carries anything the page doesn't already say, and can be skipped with empty alt text.
